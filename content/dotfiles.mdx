Everything lives here: the editor, the shell, and all the little things that make my computer feel like mine.

> Fast > fancy. A config is only useful if it gets out of the way.

## core stack components

| Tool          | What I use it for                                                                        |
| ------------- | ---------------------------------------------------------------------------------------- |
| Neovim / mvim | Writing code and these notes. Lua config, lazy.nvim, and as little friction as possible. |
| Kitty         | A terminal that keeps up. Ligatures, keyboard shortcuts, and a quiet color palette.      |
| zsh           | Moving around the filesystem and doing the small repetitive things.                      |
| Hyprland      | A keyboard-driven Wayland workspace.                                                     |

## Neovim, one little tweak at a time

My core config lives in `~/maya-nvim/`. Personal overrides go in `~/.config/mvim/init.lua`.

```lua filename="~/.config/mvim/init.lua"
return {
  theme = "savq/melange-nvim",
  options = {
    -- Keep personal tweaks here.
  },
}
```

## the boring bits that matter

Prettier for formatting. ESLint and TypeScript for catching mistakes. The same tools in the terminal and the editor, so saving a file doesn't turn into a surprise.
